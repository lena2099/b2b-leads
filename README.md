# 🌍 B2B Lead Miner

**AI-powered overseas buyer discovery for Chinese exporters.**

Automatically finds, scores, and tracks potential B2B buyers for:

| Industry | Target Buyers |
|----------|---------------|
| 🤖 Robotics & Automation | Manufacturers, integrators, distributors |
| 🔋 Energy Storage | Utilities, solar installers, project developers |

## 📊 How It Works

```
Trade Shows → Google Search → LinkedIn Match
    ↓              ↓               ↓
         DeepSeek AI Scoring + Classification
                    ↓
         Excel (.xlsx) + HTML Dashboard
```

## 📁 Output Files

| File | Description |
|------|-------------|
| `output/leads_robotics_*.xlsx` | Robotics buyer list with scores |
| `output/leads_energy_storage_*.xlsx` | Energy storage buyer list |
| `output/dashboard.html` | Interactive web dashboard |
